# Dwelly-Training-Portal

## Hosting

Deployed on Vercel in the **Dwelly Group** team (Pro), project `dwelly-training-portal`, served at
https://dwelly-training-portal.vercel.app. Every push to `main` deploys, whoever authored it.
Until October 2026 the project sat on a personal Hobby account, which blocked deploys of
commits by anyone but its owner.

The Dwelly Context Widget calls `/api/dobby/widget` at that address, so the address must not
change without a widget release.
